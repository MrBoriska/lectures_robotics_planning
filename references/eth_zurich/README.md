## Содержание

### Локальное планирование и избежание столкновений

**Метод динамического окна (Dynamic Window Approach, DWA).** Поиск ведётся
непосредственно в пространстве управлений $(v, \omega)$. Множество допустимых
скоростей определяется пересечением трёх ограничений:

$$V_r = V_s \cap V_a \cap V_d$$

где $V_s$ — конструктивные пределы приводов, $V_a$ — скорости, при которых робот
успевает остановиться до препятствия ($v \le \sqrt{2\, d\, a_{\max}}$), $V_d$ —
скорости, достижимые за один шаг дискретизации $\Delta t$. Выбор внутри $V_r$
производится максимизацией

$$G(v, \omega) = \alpha\, \text{heading}(v, \omega) + \beta\, \text{dist}(v, \omega) + \gamma\, \text{velocity}(v, \omega).$$

**Скоростные препятствия (Velocity Obstacles, VO; Reciprocal VO).**
Геометрическое построение в пространстве скоростей для расхождения с подвижными
препятствиями; обобщение на группу агентов без централизованного обмена (RVO,
ORCA).

**Потенциальные поля.** Притяжение к цели $U_{att}$ и отталкивание от
препятствий $U_{rep}$; локальные минимумы в вогнутых препятствиях. Гармонические
поля как решение уравнения Лапласа $\Delta U = 0$ с граничными условиями
Дирихле и Неймана: по принципу максимума экстремумы достигаются только на
границе, поэтому внутренних минимумов не возникает.

### Глобальное планирование

**Дорожные карты.** Граф видимости — кратчайший путь в многоугольной среде;
обобщённая диаграмма Вороного — путь с наибольшим запасом до препятствий.

**Инкрементальный поиск в изменяющейся среде.** Алгоритмы $D^*$ (A. Stentz) и
$D^*$ Lite (S. Koenig, M. Likhachev): при обнаружении нового препятствия
пересчитываются только затронутые вершины, поиск не перезапускается с нуля.
